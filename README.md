# ZJT Studio · 多功能在线工具箱

一个简洁高效的在线工具箱静态站点，聚合常用工具入口，开箱即用、无需安装。

## 功能

- 🛠️ 常用工具快捷入口
- 📦 纯静态部署，零依赖
- 📱 移动端友好响应式布局

## 在线访问

- 静态站点：https://sitong-zhang.github.io/zjt-labs/

## 本地运行

```bash
python3 -m http.server 8000
```

然后浏览器打开 http://localhost:8000/ 即可预览。
